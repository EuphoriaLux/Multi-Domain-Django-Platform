{% load i18n %} {% comment %} Coach-verified badge on a Connect member's card: how a Crush coach has confirmed that the person behind the card is real. Args: profile The CrushProfile being shown (required). variant "overlay" (default): a dark pill on the photo's right edge, for cards whose corner is free (week card, candidate card). The in-person pill keeps the top-right corner it always had; the video and voice pills sit one row below it so their longer DE/FR labels cannot collide with the coach-reviewed pill. "inline": a light pill in the card body or header, for surfaces whose corner is taken or that have no photo overlay (review card, permitted profile, chat header). Inline renders only while ``connect_real_person_badge_visible`` (context processor) is true, so those surfaces show nothing new with the flag off. The overlay needs no such check: with the flag off, ``real_person_badge`` returns only "in_person" or "", and "in_person" is the markup these cards always had: the same element, classes, icon and text, whitespace aside (the ``{% with %}``/``{% if %}`` wrapper adds blank lines around it, so a page is whitespace-equivalent to before, not byte-identical; nothing downstream caches or hashes it). css_class Optional extra classes on the inline pill (for example "self-start" in a flex column). Which pill shows comes from ``CrushProfile.real_person_badge`` (one value, so at most one pill): "in_person" (a coach attested the photo at the door), "video" or "voice" (a Connect real-person check). Load the profile with ``select_related("connect_real_person_badge")`` on any list of cards, or each card costs a query.
