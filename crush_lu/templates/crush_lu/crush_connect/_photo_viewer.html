{% load i18n static %} {% comment %} Full-screen photo viewer for Crush Connect cards: one native per page. A photo rendered with {% profile_photo ... zoomable=True %} is a button marked data-photo-viewer-open; connect-photo-viewer.js opens it here, with the other photos of its data-photo-viewer-group (one member's card) as a gallery: arrows, swipe or arrow keys move between them, Escape / the close button / a tap beside the photo closes it. The viewer reuses the address the card's already loaded, so it never shows a photo the card did not: unapproved and hidden photos stay with profile_photo and the photo endpoint (views_media.can_view_profile_photo). Included by _base_connect.html and the staff card preview. A page that shows a zoomable photo must include it, or the photo's button does nothing. {% endcomment %}
