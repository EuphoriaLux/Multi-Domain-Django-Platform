Expects `feedback_session` (the completed ConnectWeekSession) and `feedback_sentiments` (ConnectCycleFeedback.Sentiment.choices); the caller renders nothing when `feedback_session` is None. Two forms, not one with two buttons: the "not now" path must post cleanly without dragging the unfilled radio group's validation with it. Both post to the same view, which re-resolves the pending session itself — no session id travels in the form, so a stale tab cannot write feedback for the wrong week. Plain radios and a plain POST, deliberately: this page is served under a CSP that forbids inline handlers, and a survey that only works with JavaScript would silently collect nothing from the members most worth hearing from. {% endcomment %}
